<Section id="overview" title="I am Loop's first designer, and the product was designed in code before I got here.">
  <Prose>
    Loop is a Canadian business banking platform. Around four thousand
    businesses use it to hold multiple currencies, move money across borders,
    and get credit. Before this summer the company had engineers, a Storybook
    full of shipped components, and no designer.

    That shapes everything below. There was no canonical design file to work
    from, so the design system had to be reconstructed backwards out of the
    code that was already live. Every project here either feeds that system or
    consumes it: the reconciliation defines what Loop's interface is made of,
    onboarding is the largest surface that has to be built from those parts,
    the design agent generates against them automatically, and the careers page
    and support work are where the system meets things it was never specced
    for.

    Five projects, one summer, one source of truth. Pick any of them.
  </Prose>
</Section>
