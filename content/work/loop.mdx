<Section id="overview" title="I am Loop's first designer, and the product was designed in code before I got here.">
  <Prose>
    Loop is a Canadian business banking platform. Around four thousand
    businesses use it to hold multiple currencies, move money across borders,
    and get credit. Before this summer the company had engineers, a Storybook
    full of shipped components, and no designer.

    That shapes both projects here. There was no canonical design file to work
    from, so the design system had to be reconstructed backwards out of the
    code that was already live. The reconciliation defines what Loop's
    interface is made of; the design agent is what happens once that
    definition is machine-readable — it generates screens against the real
    component library, type-checks them, renders them headless, and fixes its
    own failures.

    One source of truth, and the tooling that reads from it. Pick either.
  </Prose>
</Section>
