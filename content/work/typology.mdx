<Section id="overview" title="Overview">
  <Prose>
    Typology is an infinite canvas for thinking through a plan that has
    numbers in it. Cards hold figures, cables connect them, and a change
    anywhere ripples through everything downstream. Built on Next.js and
    tldraw, with the Anthropic API doing the reasoning.

    The rule the whole thing is built around: the model does logic, not
    numbers. The user enters every figure; the agent only propagates the
    consequences. One fabricated number would destroy the trust the tool
    depends on.
